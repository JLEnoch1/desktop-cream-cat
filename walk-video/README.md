## 步骤 2 · 图生视频（人工，需账号：即梦/可灵/海螺任一）

正向提示词（直接粘贴）：

> 小猫正面原地行走，四肢交替迈步，身体轻微起伏，镜头完全固定，纯白背景，主体居中不位移，动作循环连贯

负向提示词（工具支持才填）：

> 镜头移动，镜头推拉旋转，主体位移，主体走出画面，背景变色，出现地面，阴影，倒影，多只猫，肢体变形，多余肢体，尾巴消失，写实风格，3D渲染，文字，水印，字幕

参数要点：
- 模式 = **图生视频·首帧**；时长 **3s**（2–4s 均可）；比例 1:1（随首帧自动）；分辨率最高档；运动幅度可调则取**中/低**（动作过猛 = 糊帧断肢）。
- 可灵建议加试一次**首尾帧模式：首帧 = 尾帧 = 同一张图** → 视频必然回到起始姿态，天然首尾吻合；效果别扭再退回纯首帧。
- 同提示词不同种子差异大，**出 2–3 个候选**。
- 尽量**无水印导出**；若只有带水印版本，告诉我水印在哪个角（主体四周有 ≥100px 余量，多数情况可程序化清理）。
- 成片放到本目录（如 `walk-video/walk.mp4`），或直接把视频文件发我。

## 步骤 3 · 抽帧

```bash
./walk-video/extract.sh walk-video/walk.mp4        # 15fps：3s ≈ 45 帧
./walk-video/extract.sh walk-video/walk.mp4 30     # 流畅源可抽 60 再筛
```

没有 ffmpeg 就跳过，把视频原文件给我即可。

## 步骤 4 · 验收 + 接入（视频/帧序列就位后执行）

逐帧抠图质检（单一连通域 / 轮廓闭合 / 背景纯白）→ 身高/锚点归一（灰斑锚点移植术 §9.4）→
截取首尾姿态吻合的循环段（视频漂移下通常可得 15–24 干净帧）→ 命名 `walkV01…NN` 入 `skins/default/` →
skin.json 用 §10.5 视频档参数：`interval [0.033,0.034]`、`crossfade 0~0.2`、`bobAmp 0.5~1`、`squashAmp 0`、`refSpeed` 调至爪底不打滑 → 验收清单 §7 + `npm test`。
