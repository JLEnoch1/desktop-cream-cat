安装指引（约 1 分钟）

  1. 安装并打开精力桌宠，右键桌面猫 →「打开皮肤文件夹」。
  2. 解压皮肤包，把里面的 my-cat 文件夹整个放进 skins 目录。
  3. 把同目录下原来的 default 文件夹改名为 .default（点开头的文件夹会被忽略），你的猫即上位。
  4. 桌宠约 1 秒内自动换上（也可右键 →「重新加载皮肤」）。想换回内置精力桌宠，把 .default 改回 default 即可。

皮肤目录 — macOS：~/Library/Application Support/CreamCat/skins/ · Windows：%APPDATA%\CreamCat\skins\
